# أطلس الإقليمية — GitHub Pages

موقع تعريفي لشركة أطلس الإقليمية لتوريد الأمصال والأدوية البيطرية.

## خطوات إضافة الشعار
1. احفظ صورة الشعار (الشعار الأخضر الدائري) باسم `logo.png`.
2. ضعها داخل مجلد `assets/img/` في هذا المشروع (استبدل الملف الموجود إن وجد).
3. الأبعاد المثالية: مربعة، خلفية شفافة (PNG)، لا يقل العرض عن 400px.

## هيكل صور المنتجات
المنتجات مقسّمة إلى 4 أقسام حسب الشريك، ولكل منتج مجلد شريكه الخاص داخل `assets/img/products/`:

```
assets/img/products/
  HIPRA/
  PDN/
  LaboratoiresACI/
  ZOTAL/
```

كل صورة تتبع الصيغة: `<اسم-الملف-الأساسي>_<رقم>.jpeg` — إذا كان للمنتج أكثر من صورة، تظهر تلقائياً كـ **slideshow** (أسهم + نقاط) في الموقع، وإذا كانت صورة واحدة تظهر بدون أسهم.

**لإضافة منتج جديد أو صور إضافية:**
1. ضع الصور داخل مجلد الشريك المناسب، مرقّمة بالتسلسل: `اسم_المنتج_1.jpeg`، `اسم_المنتج_2.jpeg`، ...
2. افتح [index.html](index.html) وابحث عن مصفوفة `PRODUCTS` داخل الـ `<script>` بالأسفل.
3. أضف أو عدّل عنصر بهذا الشكل:
```js
{ g: 'pdn', dir: 'PDN', base: 'pdn_my-product', count: 3, icon: '💊', title: 'اسم المنتج', desc: 'الوصف بالعربي' }
```
- `g`: مجموعة الشريك (`hipra` / `pdn` / `aci` / `zotal`)
- `dir`: اسم المجلد الفعلي
- `base`: الاسم الأساسي للملفات بدون الرقم والامتداد
- `count`: عدد الصور المتوفرة لهذا المنتج

لا حاجة لأي تعديل في CSS أو أي مكان آخر — القسم والفلتر والسلايدشو تُبنى تلقائياً من هذه المصفوفة.

## رفع الموقع على GitHub Pages
```bash
git add .
git commit -m "Add company website"
git push origin main
```
ثم من إعدادات المستودع على GitHub:
`Settings > Pages > Source > Deploy from a branch` واختر الفرع `main` والمجلد `/ (root)`.

سيكون الموقع متاحاً على:
`https://<username>.github.io/<repo-name>/`
